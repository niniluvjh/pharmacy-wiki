# AGENTS.md - 藥學國考一階核心考點 Wiki

## 1. 專案目標 (Project Goal)
本專案為個人「台灣藥學師第一階段國家考試」複習知識庫，採用 LLM Wiki 工作流運作：將學校上課講義電子檔或零散筆記放入 `raw/` 資料夾，由 AI 自動過濾冗長敘述、提煉為結構統一的國考核心考點網頁，並收錄於 `notes/` 中。
- **全站語言**：一律使用**繁體中文**（藥品學名、受體名稱、化學結構特徵與專有名詞保留英文原文並與中文並列）。
- **涵蓋六大考科**：藥理學、藥物化學、藥劑學、生物藥劑學、藥物分析、生藥學與中藥學。
- **技術架構**：純靜態網頁（HTML5 + CSS3），共用單一樣式表 `assets/style.css`，不依賴複雜前端框架，確保可在 GitHub Pages 直接瀏覽。

## 2. 資料夾與命名規範 (Directory & Naming Rules)
AI 新增或修改檔案時，必須嚴格遵守以下路徑與命名規範（檔名一律小寫英文加連字號 `-`，禁止使用中文或空白鍵）：
- `index.html`：網站首頁，依六大考科分類顯示所有已整理的筆記卡片、單元數量與快速導覽。
- `raw/`：原始素材區（存放學校上課講義 PDF 或原始筆記，**僅供 AI 讀取參考，嚴禁修改或刪除**）。
- `notes/[subject]-[topic].html`：正式考點網頁，科目字首簡寫規定如下：
  - 藥理學 `pharm-`（例：`notes/pharm-autonomic.html`）
  - 藥物化學 `medchem-`（例：`notes/medchem-beta-lactam.html`）
  - 藥劑學 `ceutics-`（例：`notes/ceutics-ointment.html`）
  - 生物藥劑學 `biopharm-`（例：`notes/biopharm-pk-basics.html`）
  - 藥物分析 `analysis-`（例：`notes/analysis-hplc.html`）
  - 生藥與中藥 `herbal-`（例：`notes/herbal-alkaloids.html`）
- `assets/style.css`：全站共用樣式表。

## 3. 視覺設計與排版風格 (Design System)
- **整體風格**：護眼、高對比、適合考前快速掃描的現代學術筆記風格（支援手機與電腦響應式 RWD）。
- **色彩規範**：
  - 頁面背景：柔和米灰 `#F8FAFC`；卡片底色：純白 `#FFFFFF`（搭配細邊框 `1px solid #E2E8F0`）
  - 學術主色：醫療深青藍 `#0F766E`（用於導覽列、主標題、表格表頭）
  - 考點強調色：琥珀橘 `#D97706`（用於「國考高頻陷阱 / 記憶口訣區塊」）
  - 警示紅標色：珊瑚紅 `#DC2626`（用於「禁忌症 / 嚴重副作用警示框」）
- **排版規範**：善用結構化比較表格（`<table>`）與項目符號清單，重要藥名、受體與機轉關鍵字須以**粗體**標示。

## 4. 新增考點頁面的標準模板 (SOP Template)
每次 AI 讀取 `raw/` 中的講義，或在 `notes/` 建立新單元頁面時，HTML 結構**必須**依序包含以下 5 個固定區塊：
1. **頂部導覽列**：顯示所屬考科標籤（Badge）與「← 返回首頁 (`../index.html`)」按鈕。
2. **單元標題與考情摘要**：單元中英文名稱，以及 3 句話以內的國考出題重點摘要。
3. **核心機轉與藥物分類比較表**：將本單元重點藥物、結構特徵或參數整理成清晰的多欄位比較表。
4. **臨床適應症、副作用與禁忌**：條列式重點整理（嚴重副作用或絕對禁忌須使用珊瑚紅警示框標出）。
5. **國考高頻陷阱與記憶口訣區**：使用琥珀橘重點卡片，整理歷屆國考易混淆觀念（例如「A 藥 vs B 藥」差異）與助記口訣。

## 5. AI 協作與驗收規則 (AI Operational Rules)
1. **講義轉化原則**：讀取 `raw/` 中的學校上課講義時，必須自動過濾非考點的基礎背景敘述，聚焦於「作用機轉、藥物分類、結構活性關係 (SAR)、臨床用途、副作用與藥物交互作用」等一階國考高頻考點。
2. **強制同步更新首頁（驗收關鍵）**：每次在 `notes/` 新增或修改任何 HTML 分頁後，**必須同步在 `index.html` 的對應考科區塊新增該單元的連結卡片與摘要**，不可遺漏。
3. **保護原始資料**：絕對不可修改、移動或刪除 `raw/` 資料夾內的任何檔案。
4. **修改前先回報**：執行建置或修改前，先簡短列出預計建立或更新的檔案清單；完成後確認所有相對路徑（`../index.html`、`../assets/style.css`）皆正確可點擊。
