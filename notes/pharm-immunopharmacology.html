免疫藥理學

Immunopharmacology：Immunosuppressants, Immunotherapies, Immunostimulators & Immunomodulators

考情摘要：最高頻為免疫抑制劑的作用靶點（Cyclosporine／Tacrolimus 抑制 calcineurin、Sirolimus 抑制 mTOR、MMF 抑制嘌呤合成）與各藥特徵性副作用。 其次為單株抗體標靶（PD-1／PD-L1／CTLA-4、TNF、IL-2R）與多發性硬化症 (MS) 用藥，以及生物製劑（Interleukin、CSF、Interferon）的用途。

3. 核心機轉與藥物分類比較

免疫反應基礎與疾病

  • Th1：細胞免疫（IL-2 促 T 細胞增生）；Th2：體液免疫（產生特異性抗體）。
  • APC 與 T 細胞交互作用分子：TCR／CD3、B7（CD80/86）與 CD28／CTLA-4、PD-1／PD-L1。
  • 免疫過度反應：移植排斥（腎、肝）、自體免疫疾病、癌症（黑色素瘤，腫瘤誘導免疫耐受）。
  • 免疫低下：原發性（SCID、DiGeorge 症候群）、續發性（AIDS、COVID-19）。

重症肌無力 (Myasthenia gravis)抗 nicotinic receptor 抗體
全身性紅斑性狼瘡 (SLE)抗磷脂質抗體
類風濕性關節炎 (RA)抗膠原抗體／類風濕因子
多發性硬化症 (MS)抗 myelin basic protein (MBP) 抗體

免疫抑制策略 CSADi（講義口訣：Cry and Sad I）

策略藥物機轉／靶點用途重點
1) Cytotoxicity
細胞毒性		Cyclophosphamide代謝出 mustard 與 acrolein（烷化劑）—
Azathioprine代謝為 6-mercaptopurine，干擾嘌呤合成—
Leflunomide代謝為 Teriflunomide；抑制嘧啶 (pyrimidine) 合成Teriflunomide：復發緩解型 MS（FDA）；Leflunomide 用於 RA（補充）
2) Selective action
選擇性作用		Mycophenolate mofetil (MMF)代謝為 mycophenolic acid，抑制淋巴球嘌呤 de novo 合成（GMP），T、B 細胞依賴此路徑，故具選擇性器官移植
Cyclosporine (CsA)與 cyclophilin 結合 → 抑制 calcineurin → IL-2↓器官移植
Tacrolimus (FK506)與 FKBP-12 結合 → 抑制 calcineurin → IL-2↓器官移植
Sirolimus (Rapamycin)PSI（Proliferation Signal Inhibitor）：抑制 mTOR，細胞週期 G1→S 受阻器官移植
TofacitinibJAK 抑制劑（講義歸於 PSI 類）RA
Basiliximab／Daclizumab抗 IL-2 受體 α 鏈（CD25）單株抗體，作用於抗原活化的 T 細胞器官移植
3) Alteration
改變免疫反應		Glucocorticoids（Prednisone）誘導 lipocortin 等抑制性蛋白，抗發炎與免疫抑制廣泛使用
Hydroxychloroquine抗發炎與免疫調節；與 TLR（toll-like receptor）相關RA、SLE、瘧疾；COVID-19（講義標問號）
4) Depletion
清除淋巴球		Muromonab (OKT3)抗 CD3 單株抗體異體移植之誘導治療 (induction)
5) Isolation
隔離淋巴球		Fingolimod（2010）、Siponimod結合 T 淋巴球上的 S1P 受體，使淋巴球困在淋巴結MS

4. 臨床適應症、副作用與禁忌

臨床適應症摘要

  • 器官移植排斥：Cyclosporine、Tacrolimus、Sirolimus、MMF、Azathioprine、Basiliximab、Glucocorticoids。
  • RA：Hydroxychloroquine、Tofacitinib、Infliximab、Etanercept；SLE：Hydroxychloroquine、Thalidomide／Lenalidomide。
  • MS：Teriflunomide、Fingolimod／Siponimod、Glatiramer、IFN-β、Glucocorticoids（急性復發）。
  • 癌症：PD-1／PD-L1／CTLA-4 抗體；C 型肝炎：IFN-α。
  • Guillain-Barré 症候群 (GBS)：疫苗的嚴重不良事件之一；急性麻痺、周邊神經軸突受損（先手腳再手臂），急性期可因呼吸衰竭致命；治療：免疫球蛋白療法。

⚠ 嚴重副作用警示

  • 感染與惡性腫瘤為所有免疫抑制劑的共通重大風險；OKT3 尤其注意 CMV、黴菌感染與細胞激素釋放症候群。
  • Cyclophosphamide：出血性膀胱炎（由 acrolein 造成）；Cyclosporine／Tacrolimus：腎毒性，須監測腎功能。
  • Fingolimod：首劑心搏過緩，需監測 6 小時。
  • IFN-α／β：憂鬱與自殺意念；IL-2：血管滲漏。
  • Filgrastim：脾臟破裂。

⛔ 使用限制與藥物交互作用

  • 講義反思題：器官移植病人長期服藥的藥物交互作用需特別注意（臨床通則：Cyclosporine／Tacrolimus 經 CYP3A4 代謝，易與誘導劑或抑制劑交互作用；講義未詳列）。
  • 免疫抑制期間感染風險高，不宜併用活性疫苗（臨床通則，講義未列）。

5. 國考高頻陷阱與記憶口訣

口訣：免疫抑制五策略 CSADi

Cytotoxicity（細胞毒性）→ Selection（選擇性）→ Alteration（改變）→ Depletion（清除）→ Isolation（隔離）。
講義諧音：「Cry and Sad I」（哭泣與悲傷）。

陷阱 1：CsA vs Tacrolimus vs Sirolimus（靶點不同）

  • CsA：cyclophilin → calcineurin；Tacrolimus：FKBP-12 → calcineurin。兩者最終都抑制 calcineurin、使 IL-2 下降。
  • Sirolimus：作用於 mTOR（G1→S），與前兩者靶點不同（補充：Sirolimus 腎毒性較低，但可有高血脂與血小板低下）。
  • 口訣：「CsA→cyclophilin，Tacrolimus→FKBP（FK506），Sirolimus→mTOR」。

陷阱 2：副作用「對號入座」

  • CsA：牙齦增生、高血壓、腎毒性。
  • Tacrolimus：糖尿病（講義 *DM 標記）。
  • Sirolimus：血小板低下、高三酸甘油酯。
  • Cyclophosphamide：出血性膀胱炎；MMF：嗜中性球低下；Azathioprine：骨髓抑制。

陷阱 3：Azathioprine／MMF／Leflunomide 都干擾核酸，但路徑不同

Azathioprine → 6-MP（嘌呤）；MMF → 抑制嘌呤 de novo（GMP），淋巴球依賴此路徑；Leflunomide／Teriflunomide → 嘧啶。
口訣：「Azathio 與 MMF 是嘌呤，Lefluno 是嘧啶」。

陷阱 4：抗體藥的標靶 — 看字尾與對象

  • Basiliximab／Daclizumab → IL-2 受體 α 鏈（CD25）；Muromonab → CD3。
  • Pembrolizumab／Nivolumab → PD-1；Atezolizumab → PD-L1；Ipilimumab → CTLA-4。
  • Infliximab（抗 TNF 抗體） vs Etanercept（TNF 誘餌受體）。
  • Bevacizumab／Ranibizumab → VEGF；Ramucirumab → VEGF 受體；Cetuximab／Necitumumab → EGFR。

口訣：「P-1、P-L1 解除煞車；Ipi 拿掉 CTLA-4 的剎車」，副作用＝irAE（皮膚、肺炎、結腸炎）。

陷阱 5：MS 用藥 vs 非 MS 用藥

MS 可用：Glucocorticoids、IFN-β、Glatiramer、Fingolimod／Siponimod（S1P）、Teriflunomide。Tofacitinib 是 JAK 抑制劑、用於 RA，不是 MS 藥物。

講義 Quiz（第 36 頁）

題目：41 歲男性，MS 病史六個月，使用 methylprednisolone 與 IFN 維持，現肢體無力加重、失禁、部分視力喪失，疑似復發。下列何者不適當？
A. Teriflunomide　B. Fingolimod　C. Glatiramer　D. Tofacitinib

答案：D。Tofacitinib 為 JAK 抑制劑，用於 RA；其餘三者皆為 MS 治療藥物。

陷阱 6：IFN、IL-2、CSF 的「用途／副作用」配對

  • IFN-α → C 肝；IFN-β → MS；IFN-γ → 免疫刺激、感染。
  • Filgrastim（G-CSF）→ 嗜中性球；Sargramostim（GM-CSF）；Oprelvekin（IL-11）→ 血小板。
  • IL-2（Aldesleukin）→ 血管滲漏；IFN → 憂鬱。
